# My DSA Journey

This repository documents my ongoing journey of learning data structures and algorithms. It brings together coursework and practice from my college days and will continue to grow as I study new topics, revisit old solutions, and solve more problems.

## Repository Structure

```text
.
├── courses/   # Exercises, notes, and implementations from structured courses
└── practice/  # Problems solved across coding platforms and independent practice
```

### Courses

The `courses/` directory currently includes material from:

- Coding Ninjas data structures and algorithms
- Coding Ninjas programming abstractions
- Coursera's Algorithmic Toolbox
- freeCodeCamp dynamic programming and graph courses
- IIT coursework

### Practice

The `practice/` directory contains solutions from:

- Leetcode/Neetcode
- CodeStudio
- GeeksforGeeks
- HackerEarth
- Foundational C exercises

## Goals

- Build a strong foundation in data structures and algorithms
- Practice problem-solving consistently
- Preserve earlier work while improving solutions over time
- Explore multiple approaches and analyze their time and space complexity
- Maintain a long-term record of my progress
